# Releasing & Sideloading Statocyst for iOS

This document covers building, sideloading, and publishing Statocyst for iOS (`com.hopefulaspirationsindustries.statocyst`).

## 1. Syncing Web Assets

Whenever the Angular renderer changes, build the web assets and sync them into `ios/App/App/public`:

```bash
pnpm run ios:sync
```

(`ios/App/App/public` is git-ignored and generated by `cap sync ios`.)

## 2. Versioning

In `ios/App/App.xcodeproj/project.pbxproj`, keep both version keys aligned with `android/app/build.gradle`:

- `MARKETING_VERSION = 1.9.0;` (matches `versionName`)
- `CURRENT_PROJECT_VERSION = 27;` (matches `versionCode`, strictly increasing integer)

## 3. Sideloading the CI `.ipa`

Every CI run (and every tagged GitHub Release) produces an ad-hoc signed `Statocyst.ipa` artifact (`statocyst-ios-ipa`) that can be installed with standard iOS sideloading tools:

### Option A: Sideloadly (macOS / Windows)
1. Download and unzip the `statocyst-ios-ipa` artifact from GitHub Actions to get `Statocyst.ipa`.
2. Connect your iPhone or iPad via USB (or Wi-Fi) and open **Sideloadly**.
3. Drag `Statocyst.ipa` into Sideloadly, enter your Apple ID, and click **Start**.
4. On your iOS device, open **Settings → General → VPN & Device Management**, select your Apple ID under *Developer App*, and tap **Trust**.
5. On iOS 16+, enable **Settings → Privacy & Security → Developer Mode** if prompted.

### Option B: AltStore / SideStore
1. Download `Statocyst.ipa` onto your iPhone/iPad (into the Files app).
2. Open **AltStore** or **SideStore** → **My Apps** → tap **`+`** in the top-left corner.
3. Pick `Statocyst.ipa` from Files. AltStore/SideStore will sign and install Statocyst using your Apple ID.

### Option C: Direct Xcode Install (macOS)
1. Run `pnpm run ios:sync`.
2. Open `ios/App/App.xcodeproj` in Xcode (`npx cap open ios`).
3. Select the **App** target → **Signing & Capabilities**, check **Automatically manage signing**, and select your **Personal Team** (free Apple ID) or paid Apple Developer Team.
   - If using a free Apple ID and the bundle identifier is already claimed globally, append a personal suffix in Xcode (e.g. `com.hopefulaspirationsindustries.statocyst.dev`).
4. Select your connected iPhone from the run destination menu and press **Cmd + R**.

## 4. App Store Connect / TestFlight Archive

1. Ensure `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION` are incremented in `ios/App/App.xcodeproj/project.pbxproj`.
2. Run `pnpm run ios:sync`.
3. In Xcode, select **Any iOS Device (arm64)** as the destination and choose **Product → Archive**.
4. In the Organizer window, click **Distribute App → App Store Connect → Upload**.
5. Because `ITSAppUsesNonExemptEncryption` is set to `false` in `ios/App/App/Info.plist`, TestFlight builds skip the export compliance prompt automatically.
