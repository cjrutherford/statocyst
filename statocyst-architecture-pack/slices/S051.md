# S051 — iOS podcast playback and downloads

**Milestone:** MVP-5 Podcasts
**Status:** BLOCKED (depends on S050; macOS/Xcode unavailable)
**Depends on:** S046, S047, S050

## Objective

Make the native iOS playback manager authoritative for podcasts: background audio, queue,
resume, speed, remote commands and offline pins, matching Android's behavior.

## Scope and boundaries

- Native podcast queue and playback state persisted in SQLite; one active context shared
  with music (start podcast pauses music and vice versa).
- `AVPlayer.rate` for speed; resume writes on pause/seek/switch/teardown and periodic ticks;
  completion threshold; played/completed; mark unplayed.
- Now Playing info: show, episode, artwork, duration, speed; `MPRemoteCommandCenter`
  play/pause/skip/seek with podcast intervals.
- Native podcast source resolution for downloads; pin/unpin; resume/retry; offline playback
  from the protected download.
- `LocalMediaServer` serves downloaded episode files and artwork.
- No CarPlay browse (S052), no background feed refresh.
- Keep music playback, downloads and existing tests unchanged.

## Acceptance gate

- Background audio continues with the app backgrounded and the screen locked.
- Resume works after pause, seek, context switch and app termination/relaunch.
- Completion advances; a completed episode restarts at 0.
- Speed and skip intervals work from the lock screen/remote commands.
- A pinned episode plays in airplane mode; an unpinned one fails with clear copy.
- Music playback and downloads regressions pass.
- iOS build/tests pass; device or simulator evidence is recorded.
- Evidence recorded in `evidence/S051-report.md`.

## Required execution steps

1. Add native podcast queue/state persistence and context switching.
2. Wire AVPlayer rate, Now Playing info and remote commands.
3. Add resume writes and completion transitions.
4. Add podcast source resolution to the native downloader and offline path.
5. Run background/lock-screen/offline checks.
6. Record evidence.

## Completion rule

VERIFIED only with background, relaunch and offline evidence on the iOS runtime. A
compile-only result is IMPLEMENTED_UNVERIFIED.
