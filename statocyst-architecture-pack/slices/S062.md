# S062 — MVP-6 verification, performance and release gate

**Milestone:** MVP-6 Video podcasts
**Status:** PLANNED
**Depends on:** S056–S061

## Objective

Prove the whole video-podcast story on real runtimes, close cross-platform gaps and make the
MVP-6 release decision. This slice may fix defects but may not add deferred features.

## Scope and boundaries

- End-to-end matrix: RSS video add/refresh → play → video/audio-only → background/screen-off
  → PiP → seek → resume → restart; YouTube probe/add/classify → play audio in background →
  companion offline/restart → unpair; RSS video/audio pin → offline; YouTube
  streaming-only/no-pin state.
- Performance: screen-off 60-minute audio on Android/iOS; hidden-video CPU/battery on
  desktop; 1080p video playback; large RSS video pin/quota; startup with the companion
  offline.
- Security audit: token/cookie/media-URL redaction, companion auth/version, no arbitrary URL
  proxy, SSRF on feed URLs, no extraction symbols/binaries in core artifacts.
- Legal/UX review: notice before first YouTube source, experimental labelling, store copy,
  no-re-hosting posture, iOS absence of YouTube.
- Migration replay from real v6 desktop, v7 Android and v6 iOS databases.
- Accessibility/theme pass on video controls; reduced motion; focus return from PiP.
- Docs: user help for video and YouTube, companion setup, troubleshooting, privacy note,
  release notes with platform limitations.
- Evidence S054–S062 completed; blocked gates recorded exactly.

## Acceptance gate

- Every item in the MVP-6 release gate (`roadmap/VIDEO_PODCASTS.md` §9) is demonstrated or
  explicitly BLOCKED.
- Video RSS podcast plays with background audio on desktop, Android and iOS; restart/resume
  works; no music/audio-podcast regression.
- Desktop YouTube works against the fixture companion and a recorded live result; Android
  works over the companion or is explicitly BLOCKED; iOS has no YouTube surface.
- RSS video pins respect quota, play offline and remove cleanly. YouTube episodes expose no
  pin and an unresolved stream without the companion fails with clear copy.
- Security and legal checks pass; no extraction dependency in any core artifact.
- Performance results are recorded on named references; no arbitrary thresholds.
- Evidence and artifact links are committed; the roadmap/ADR status is updated.

## Required execution steps

1. Run the full desktop/Android/iOS matrix, including background, PiP and offline.
2. Run the performance scenarios and record device/desktop numbers.
3. Run the security/redaction and packaging audits.
4. Replay migrations from real databases; verify backups.
5. Run the legal/UX and accessibility checks; fix only release-blocking issues.
6. Complete `evidence/S054-report.md`–`S062-report.md`; update the roadmap and release
   decision.
7. If YouTube on any platform is not viable, mark it BLOCKED with a reproduction recipe and
   ship the compliant RSS video path without claiming YouTube parity.

## Completion rule

VERIFIED only when the release gate is fully evidenced. Any partial platform or legal result
keeps MVP-6 at IMPLEMENTED_UNVERIFIED or BLOCKED; it is not shipped as “all platforms”.
