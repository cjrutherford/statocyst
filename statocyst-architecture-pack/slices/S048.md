# S048 — Android podcast data and ingestion

**Milestone:** MVP-5 Podcasts
**Status:** IMPLEMENTED_UNVERIFIED (emulator verified; physical device/real key pending S053)
**Depends on:** S043, S044, S045

## Objective

Bring the shared podcast library to Capacitor Android with native fetching, secure
credentials, Room persistence and no CORS dependency. The renderer keeps the shared parser
and UI; Android provides transport, storage and art.

## Scope and boundaries

- Room v7 podcast tables and `mediaKind` filtering (from S042) exposed through DAOs.
- Plugin methods: `fetchPodcastFeedXml`, generic directory fetch, `savePodcastFeed`,
  `savePodcastEpisodes`, `listPodcastFeeds`, `listPodcastEpisodes`, `updatePodcastFeed`,
  `removePodcastFeed`, `setEpisodePlayed`, `cachePodcastArtwork`.
- OkHttp fetch policy: conditional GET, timeouts, body cap, redirect cap, SSRF guard,
  content-type checks. No WebView fetch and no CORS reliance.
- Shared TS `PodcastBridge` implementation in `capacitor-bridge.ts`: native fetch → shared
  parse → native persist; foreground refresh of due feeds; manual refresh.
- Secrets in `EncryptedSharedPreferences`; never in Room or logs.
- Artwork cached into app files and served by the native media/art path.
- No native playback queue changes here (S049), no car browse (S052).

## Acceptance gate

- On a device, add a feed by URL, parse it with the shared library, persist feed/episodes,
  restart the app and see the same library.
- Refresh discovers new episodes and preserves resume/played/download fields; a failed feed
  is isolated.
- Private/loopback URLs and redirects to private addresses are blocked.
- Directory search returns Apple/Fyyd results through the host fetch path; no user key is
  required and no secret is stored in Room or logs.
- Music `listTracks`/stats/browse return no podcast rows.
- Room migration v6 → v7 preserves existing data.
- Android unit/instrumented tests and Gradle build pass.
- Evidence recorded in `evidence/S048-report.md`.

## Required execution steps

1. Add Room entities/DAOs and plugin persistence methods; unit-test mapping.
2. Implement OkHttp fetcher and SSRF guard; return a bounded XML payload.
3. Implement the Capacitor bridge orchestration and foreground refresh.
4. Add keyless directory fetch/search through the native transport.
5. Add art cache.
6. Run instrumentation, build and device evidence.
