# S039 — CarPlay audio integration

**Milestone:** Rural offline / iOS parity
**Status:** PLANNED
**Depends on:** S033, S034

## Objective
Ship a first-class CarPlay audio experience: browse the local catalog, see Now Playing,
and control playback without booting the WebView.

## Scope and boundaries
- `com.apple.developer.carplay-audio` entitlement and `CPTemplateApplicationScene` manifest.
- `CarPlaySceneDelegate` with `CPListTemplate` browse: Library, Albums, Artists, Playlists, Downloaded.
- `CPNowPlayingTemplate` sharing the existing `PlaybackManager` and `MPRemoteCommandCenter`.
- Artwork via the existing `LocalMediaServer`; offline and empty states.
- No new server API; no WebView dependency.
- Entitlement approval and real head-unit testing are external gates.

## Acceptance gate
- The iOS target compiles with the CarPlay scene and templates.
- A simulator build launches without a CarPlay-connected crash.
- Browse paths return the same catalog rows as the phone UI.
- Now Playing reflects play/pause/skip/seek from `PlaybackManager`.
- Real CarPlay validation is recorded as BLOCKED until the entitlement is granted.

## Required execution steps
1. Add the entitlement file and scene manifest; document provisioning.
2. Build a pure browse model with unit-testable inputs.
3. Implement the scene delegate and templates.
4. Run the iOS CI build; record the entitlement/head-unit blocker exactly.
5. Record evidence in `evidence/S039-report.md`.
