# S038 — Mobile UX polish

**Milestone:** Rural offline
**Status:** PLANNED
**Depends on:** S030

## Objective
Make the phone build feel native and tell the truth about where audio is coming from.

## Scope and boundaries
- Virtualize the library list; keep keyboard accessibility.
- Swipe actions: Play, Queue, Pin; sticky download action with size.
- Compact player bar on the library; full transport on Now Playing.
- Copy: "Streaming from <server>" vs "On this device"; remove the false local-only claim.
- First-run connect + "pin an album for the commute"; global connectivity chip.
- Undo for destructive removal.

## Acceptance gate
- A 10k-row library scrolls at target frame rate on the reference device.
- No local-only claim is shown while a Jellyfin server is active.
- First-run flow reaches a playable track without opening Settings.
- Undo works for remove-download and remove-track.
- Evidence in `evidence/S038-report.md`.
