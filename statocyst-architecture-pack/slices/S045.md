# S045 — Podcast library and discovery UI

**Milestone:** MVP-5 Podcasts
**Status:** IMPLEMENTED_UNVERIFIED (E2E verified; a11y/10k/mobile gates pending S053)
**Depends on:** S044, S046

## Objective

Give the shared Angular renderer a complete podcast library: subscriptions, show detail,
episode lists, directory discovery, show notes and the podcast queue surface, without
polluting the music library. Users search existing directories and subscribe in one tap;
there is no user-facing URL or OPML source flow.

## Scope and boundaries

- New **Podcasts** navigation destination and internal show/episode navigation using
  `PodcastsStore` + bounded history.
- Podcasts home: Continue Listening, New Episodes, subscriptions, refresh status, add
  button.
- Show detail: artwork, metadata, subscribe/refresh, per-show settings (interval, speed,
  skip, sort, auto-queue), episode list with all/unplayed/downloaded filters and season
  grouping.
- Discover podcasts: directory search (Apple/Fyyd), topic chips, source badges,
  one-tap subscribe, clear empty/error states. No URL field or user credentials.
- Episode row: progress, played/completed, download state, overflow actions.
- Show notes: plain text and safe external links; no raw HTML.
- Podcast queue view with active-context indication.
- Music separation: library tracks/stats/albums/radio/playlists/favorites exclude podcast
  rows; podcast counts are separate.
- Windowed episode lists and keyboard/accessibility support.
- Player-bar podcast affordances are wired in S046; this slice can render their layout.

## Acceptance gate

- A user can add a feed from the fixture server, see the show, open episodes, read show
  notes, mark played/unplayed, change per-show settings and unsubscribe.
- Directory search and one-tap subscribe work in the UI with the S044 service; provider
  attribution and partial failures are visible.
- Empty, loading, offline, feed-error and no-directory states are clear and actionable.
- Music views, stats, radio, playlists and favorites do not show podcast rows.
- Show notes never render raw HTML; only HTTP(S) links can be opened externally.
- 10,000 episodes remain usable through paging/windowing; no full-list render.
- Keyboard-only navigation and screen-reader labels pass the accessibility check.
- Desktop Playwright E2E covers add → show → episode → settings → unsubscribe.
- Evidence recorded in `evidence/S045-report.md`.
