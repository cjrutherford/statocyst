# S035 — One sparse cache

**Milestone:** Rural offline
**Status:** PLANNED
**Depends on:** S033, ADR-036

## Objective
Replace the whole-file rolling cache with a sparse media cache so partial data is playable
and there are not two competing copies of the same track.

## Scope and boundaries
- ExoPlayer `SimpleCache` + `CacheDataSource` for the rolling cache.
- Pinned downloads stay separate and are never evicted.
- One budget, one LRU policy, one reconciliation path.
- Migrate or clear the old `filesDir/cache` once, with a user-visible note.
- No changes to pin semantics.

## Acceptance gate
- A partially cached track plays offline up to the cached range and fails gracefully past it.
- No duplicate pin+cache file for the same track.
- Budget and eviction tests pass; migration is safe on an existing install.
- Evidence in `evidence/S035-report.md`.

## Required execution steps
1. Write ADR-036 and a migration/rollback plan.
2. Add a failing cache-span test before implementation.
3. Implement behind a feature flag; compare old and new cache stats.
4. Record evidence.
