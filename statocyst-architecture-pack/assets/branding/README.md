# Statocyst Branding Assets

This folder contains the current approved Statocyst icon set.

## Master reference

- `statocyst-icon-primary.png` is the approved primary app icon.
- The **central suspended pearl / bubble** is a required part of the mark and should remain visible in downstream variants.
- `statocyst-symbol-transparent-master.png` is the transparent symbol derived from the approved primary icon for adaptive, transparent, and composited uses.

## Important brand notes

1. Preserve the luminous jellyfish silhouette, suspended pearl/bubble, and sonar-wave motif.
2. Do not replace the center pearl with a generic play button or remove it in future icon exports.
3. Use the primary icon for desktop and opaque app-store contexts.
4. Use the transparent symbol for adaptive, layered, or composited branding contexts.
